PERSONAL PORTFOLIO WEBSITE
==========================

FILES
- index.html  : page content and semantic HTML sections
- style.css   : separate responsive styling
- script.js   : interactive JavaScript features

HOW TO PREVIEW
1. Extract the project ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Test the navigation, dark mode and contact form validation.

PERSONALISE BEFORE SUBMISSION
- Replace "Your Name" and "YN" with your own name and initials.
- Update the About Me paragraph to describe yourself in your own words.
- Keep only skills you have actually studied.
- Replace the two sample projects with your own work if needed.
- Add your real email and GitHub profile links.
- Do not publish private phone numbers or home addresses.

REQUIREMENTS INCLUDED
- Semantic header, nav, main, section and footer elements
- Home/About, Skills, Projects (2 examples) and Contact sections
- Contact form
- Separate style.css file
- Element, class and ID selectors
- Hover effects
- Responsive media queries for mobile screens
- JavaScript: mobile navigation, dark mode and contact form validation

IMPORTANT
The contact form currently validates input in the browser only. It does not send or store messages.
To receive messages, a backend or form service would need to be connected.

GITHUB PUBLISHING
1. Sign in to https://github.com
2. Create a new public repository, for example: my-portfolio
3. Upload index.html, style.css, script.js and README.txt.
4. Open the repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the main branch and root folder, then Save.
7. GitHub will provide a public website URL after deployment.
